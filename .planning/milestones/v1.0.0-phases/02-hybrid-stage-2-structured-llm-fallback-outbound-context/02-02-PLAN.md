  <id>T-02-03</id>
  <description>Outbound Context Confusion: O contato responde negativamente ao imóvel abordado na campanha mas manifesta interesse em outro imóvel; o sistema associa erroneamente o imóvel antigo à nova oportunidade.</description>
  <mitigation>O orquestrador separa explicitamente o imóvel recusado (not_interested_property no SeededCandidate) e instancia um segundo PropertyCandidate independente para a nova oferta (CAPTURE_OTHER_PROPERTY).</mitigation>
  <asvs_level>Level 1</asvs_level>
</threat>
<threat>
  <id>T-02-04</id>
  <description>Fragmented Message Race Condition: Múltiplas mensagens enviadas em rajada pelo usuário geram execuções concorrentes duplicando oportunidades no CRM.</description>
  <mitigation>O coalescer agrupa mensagens no intervalo da TurnWindow sob a mesma chave idempotente de turno, garantindo uma única execução agregada.</mitigation>
  <asvs_level>Level 1</asvs_level>
</threat>
