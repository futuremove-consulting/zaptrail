  <id>T-04-02</id>

  <mitigation>Verificação imediata via `storage.isProcessed(tenantId, provider, externalMessageId)`; se já processado, retorna imediatamente o envelope salvo com `duplicate: true` e status HTTP 200 sem reprocessamento.</mitigation>
  <asvs_level>Level 1</asvs_level>
</threat>
